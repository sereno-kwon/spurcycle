# Spurcycle 코리아 — spurcycle.rubiworkshop.com

quoc.rubiworkshop.com과 같은 Rubi 디자인 체계(Pretendard + 에스코어 드림, 흑백·얇은 라인)로 만든 정적 사이트입니다. GitHub Pages로 배포됩니다.

- `index.html` 페이지, `style.css` 스타일(QUOC 페이지와 동일 체계), `script.js` 히어로 슬라이드·메뉴·라이트박스
- `images/**.svg` 는 **임시 이미지(placeholder)** 입니다. 실제 사진으로 바꿀 때는 같은 경로에 `.jpg`를 넣고 `index.html`의 확장자를 바꿔 주세요.
- 스펙 표에 `TODO` 주석이 있는 곳은 공식 스펙(무게, 핸들바 지름, 컬러) 확인이 필요합니다.
